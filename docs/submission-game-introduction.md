# 게임 제목

꿈을 되돌리는 아이

# 게임 소개 (200자 이내)

《꿈을 되돌리는 아이》는 악몽에 갇혀 감정을 잃어가는 친구들을 구하기 위해, 윤호가 꿈을 훔쳐 딸의 행복을 지키려는 수면 과학자와 맞서는 픽셀 액션 퍼즐 어드벤처입니다. 과거의 나를 기록하고 공명으로 꿈의 규칙을 바꿔 모두의 꿈을 되돌리세요.

# Codex와 함께 게임을 만든 과정 (선택)

## Codex 활용

기획자가 자연어로 스테이지의 감정, 조작감, 문제 상황을 설명하면 Codex가 HTML·CSS·JavaScript 기반 프로토타입으로 구현하고, 실제 플레이 피드백을 반영해 반복 수정하는 방식으로 개발했습니다. Codex는 단순 코드 생성 도구가 아니라, 기획 의도를 실행 가능한 스테이지 구조·상태 규칙·UI 문구로 옮기고 빌드와 GitHub 배포까지 점검하는 협업 도구로 사용했습니다.

## Codex로 구현한 기능과 해결한 문제

- `K`로 현재 이동을 기록해 과거의 나를 남기는 기억 협동 퍼즐, `L` 공명 파장으로 숨은 길·발판을 드러내는 규칙, 상상력 게이지와 실패 연출을 구현했습니다.
- 하린·유나·하늘·딸·수면 과학자 보스를 서로 다른 감정 게임으로 구성했습니다. 예를 들어 유나 보스는 공명과 박자 회피, 하늘 보스는 바람 방향·질주·반사, 최종 보스는 기억 탄환과 TRUE MEMORY 단계로 설계했습니다.
- 발판 충돌, 보스전 진입·페이즈 전환, 막힌 출구, 이동 발판 속도, 역풍 물리, 기억 잔상 소멸 같은 실제 플레이 오류를 코드로 확인하고 수정했습니다.
- 기억 발판·게이트·표지판의 상호작용 규칙, WASD 조작 안내, 보스 안내, 스토리 오버레이의 글자 크기·여백·잘림 문제를 통일했습니다.
- 픽셀 아트 리소스와 배경음악을 게임에 연결하고, 썸네일·대회 제출용 문서·GitHub Pages 공개 링크를 제작했습니다. `main` 브랜치에 푸시하면 공개 페이지가 자동으로 갱신되도록 배포 흐름도 설정했습니다.

## 사람이 직접 결정한 부분

팀은 이야기의 핵심인 ‘딸을 사랑하지만 타인의 꿈을 빼앗는 잘못된 선택을 한 아버지’, 윤호와 친구들의 관계, 각 친구가 두려워하는 악몽의 주체, 최종 결말의 감정선을 직접 정했습니다. 또한 스테이지별 난이도와 재미의 기준, 보스가 주는 감정, 픽셀 아트의 분위기·색감·의상·구도, 음악의 방향은 실제 플레이를 통해 팀이 판단하고 선택했습니다. Codex의 제안은 그대로 채택하지 않고, 팀의 피드백과 테스트를 거쳐 기획 의도에 맞는 결과만 반영했습니다.
