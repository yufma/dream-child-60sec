# 꿈의 연결 — 대회 제출용 데모 영상 구성안

## 제출 사양

- 최종 길이: **2분 32초 이내**
- 권장 출력: `1920 × 1080`, 16:9, 60 fps, H.264 MP4
- 오디오: 게임 BGM과 효과음을 중심으로 사용. AI 더빙은 넣지 않고, 핵심 문장을 짧은 자막으로 처리한다.
- 실제 플레이: 0:24~2:09 구간을 중심으로 **약 105초** 확보한다. 게임 HUD, 상상력 게이지, 조작·기믹 반응이 보이게 녹화한다.
- 제목 표기: 영상의 첫 6초와 마지막 9초만 사용한다. 중간에는 긴 설명 카드 대신 1문장 자막만 넣는다.

## 편집의 핵심 원칙

1. **스토리 → 조작 → 기믹 → 보스 → 감정적 결말** 순서로 이해되게 한다.
2. 실제 플레이 장면은 과도하게 빠르게 돌리지 않는다. `입력 → 반응 → 성공`이 한 쇼트 안에서 읽혀야 한다.
3. 자막은 하단 중앙에 1~2줄만 두고, 게임의 HUD·보스 체력·상상력 게이지를 가리지 않는다.
4. 전환은 흰 플래시보다 기억 에너지의 청록·금색 리본 와이프 또는 6~10프레임 디졸브를 쓴다.
5. 컷마다 녹화 원본을 앞뒤로 3~5초 더 확보해 편집 여유를 둔다.

## 촬영 순서

편집 시간보다 녹화 시간을 줄이기 위해 아래 순서로 각 스테이지에 들어간다. 한 장면마다 **성공 테이크 2개**를 확보한다.

1. 타이틀 화면과 프롤로그 전체를 한 번 녹화한다.
2. 1, 2, 3스테이지를 차례로 녹화한다. 특히 2스테이지는 복원 시작 전 3초와 완성 후 3초를 남긴다.
3. 10스테이지에서 기억 발판 위의 유령 잔상, L 공명으로 드러나는 길, 실제 점프 성공을 한 테이크 안에 넣는다.
4. 15스테이지에서 역풍으로 한 번 밀려나는 장면을 먼저 찍고, K 기록 이후 기둥이 무너지는 성공 장면을 찍는다.
5. 5·11·17·22 보스는 시작 안내 화면이 아니라 **HUD가 보이는 실전 장면**만 사용한다. 보스별로 15~25초 원본을 녹화한다.
6. 22스테이지를 클리어한 뒤 기억 매듭과 엔딩 일러스트를 끝까지 별도 녹화한다.

## 오디오 편집

- 시작: 타이틀에 맞춰 희미한 숨소리/꿈 입자 효과 후 프롤로그 음악을 서서히 올린다.
- 일반 플레이: 각 챕터 BGM을 그대로 유지하고, 컷 전환 때 0.2~0.4초 크로스페이드만 사용한다.
- 유나 보스: 공명 발판이 켜지는 박자와 컷을 맞춘다.
- 22스테이지: 격정적 보스 BGM을 TRUE MEMORY 순간에 가장 크게 두고, 기억 매듭이 완성될 때 효과음만 남긴 뒤 엔딩 BGM으로 자연스럽게 넘긴다.
- 최종 음량: BGM은 평균 -18~-14 LUFS 수준을 목표로 하고, UI 효과음이 자막을 읽는 순간을 덮지 않게 한다.

## 엔드 카드

아래 세 요소만 남긴다. 과도한 설명은 넣지 않는다.

```text
꿈의 연결
누구의 꿈도 빼앗기지 않는 아침을 위해
yufma.github.io/dream-child-60sec/
```

제출 페이지가 QR 코드를 허용하면 링크 아래 오른쪽에 작은 QR 코드만 추가한다. 엔딩 일러스트의 딸과 과학자 표정은 가리지 않는다.

## 편집 전 체크리스트

- [ ] 전체 영상이 3분 미만이며 권장본은 2분 32초 이내다.
- [ ] 실제 플레이가 1분 이상이고 HUD·게이지·조작 반응이 보인다.
- [ ] K, L, Space, J 중 최소 K·L·J가 실제 성공 결과와 함께 등장한다.
- [ ] 세 친구 보스와 최종 보스가 서로 다른 방식으로 보인다.
- [ ] 엔딩에서 딸은 깨어나지 않고, 평온하게 미소 짓고 있다.
- [ ] 처음과 마지막에 게임명·공개 링크가 정확하게 표기된다.
