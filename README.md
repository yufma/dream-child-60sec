# 꿈을 잇는 아이

OpenAI Game Builders Seoul을 위한, 외부 의존성이 없는 브라우저 게임 프로토타입입니다. 이 버전은 꿈속 액션 어드벤처의 **22개 스테이지 캠페인**을 플레이할 수 있는 버티컬 슬라이스입니다.

## 이야기

수면 과학자는 의식 없는 딸이 머무는 완벽한 꿈을 유지하기 위해 다른 아이들의 꿈과 감정을 빼앗습니다. 전 조수의 도움으로 꿈에 접속한 **윤호**는, 첫 번째 친구 **하린**의 악몽 속에서 빼앗긴 **웃음 코어**를 되찾습니다.

윤호의 능력은 초능력이 아니라 “그럴 수도 있다”고 믿는 어린아이의 상상력입니다. 그 믿음은 꿈 추출기의 시간만 잠시 멈추고, 숨은 공명 길을 드러내며, 짧은 질주로 탄막 사이를 파고듭니다.

## 실행

`index.html`을 브라우저에서 열면 실행됩니다. 배포 시 정적 호스팅에 세 파일을 그대로 올리면 됩니다.

## 조작

- 이동: `A` / `D` (방향키도 지원)
- 퍼즐 점프: `W` (↑ 키도 지원)
- 보스전 회피: `W` / `A` / `S` / `D`
- 기억 기록/되감기: `K` (한 번 눌러 기록 시작, 다시 눌러 과거의 나를 남기고 시작점으로 되감기)
- 기억 기록 취소: `I`
- Rule 01 — 멈춘 순간: `Shift`를 누르고 있는 동안 추출기의 시간 정지, 초당 상상력 28 소모
- Rule 02 — 공명 파장: `L`을 누르고 있는 동안 숨은 공명 길과 봉인을 드러냄, 챕터에 따라 초당 상상력 14~18 소모
- Rule 03 — 질주: `Space`로 짧게 앞으로 돌진
- 최종 보스 기억 탄환: `J` (수면 과학자 공격 단계 해금 후)
- 스테이지 메뉴: `Esc` (다시 누르면 현재 스테이지로 복귀)

## 스테이지 해금과 재도전

현재는 개발 점검 모드로, `Esc`를 눌러 여는 꿈의 경로 메뉴에서 22개 스테이지를 모두 바로 선택할 수 있습니다. 클리어 정보와 배운 기술은 현재 브라우저에 저장됩니다. 출시 버전에서는 이전 스테이지 클리어 시 다음 스테이지가 열리는 방식으로 되돌릴 수 있습니다.

## 상상력 게이지

윤호의 기술은 모두 상상력을 사용합니다. `Shift` 시간 정지는 초당 28, `L` 공명은 챕터에 따라 초당 14~18을 소모합니다. `Space` 질주는 즉시 12, 최종 보스전의 `J` 기억 탄환은 한 번에 6을 소모합니다. 기술을 쓰지 않으면 게이지가 회복됩니다. 기억의 나는 추가 유지비 없이 남아 있지만, 기록을 만들 때마다 상상력이 소모됩니다. 게이지가 낮아질수록 화면이 흐려지고, 0이 되면 친구의 꿈과 연결이 끊겨 해당 스테이지를 다시 시작합니다.

## 기억 루프 — 이 게임의 핵심

`K`를 누르면 현재 위치부터 움직임이 기록됩니다. 원하는 곳까지 이동한 뒤 `K`를 한 번 더 누르면 윤호는 기록 시작 위치로 되감기고, **기억의 나**가 방금 전 행동을 재생한 뒤 마지막 위치에 남습니다. 기록 중에 실수했다면 `I`로 취소할 수 있습니다.

- 과거의 나는 최대 3명까지 남길 수 있습니다.
- 기억 발판 위에 마지막 위치를 남기면 꿈의 문과 길이 열립니다.
- 기억의 나는 추가 유지비 없이 남아 있어, 퍼즐 풀이 중 지나친 난이도 상승을 막습니다.
- 기억의 나 위로 점프하면 짧은 움직이는 발판처럼 활용할 수 있습니다.
- 이 기능은 단순 분신이 아니라 윤호와 친구가 함께했던 시간을 실제 게임 규칙으로 바꾸는 장치입니다.

## 22개 스테이지 캠페인

| 구간 | 스테이지 | 핵심 보스/규칙 |
| --- | --- | --- |
| 하린 | 1~6 | 5: 공격 없이 세 기억을 맞추고 `Shift`로 하린을 안심시키는 공포 진정전 |
| 유나 | 7~12 | 11: 기억의 나 둘을 화음 앵커에 남기고, `L` 공명으로 여섯 음을 되찾으며 음표 탄막을 피하는 합창 보스전 |
| 하늘 | 13~18 | 17: 기억의 나를 돌풍의 미끼로 세 번 쓰고, 열린 고리 네 개를 `Space` 질주로 뚫는 추격 보스전 |
| 과학자의 딸 | 19~21 | 21: `L`로 균열을 드러낸 후 거울 파편을 피하며 `Space` 질주로 네 균열을 통과하는 수호자 보스전 |
| PAGE 02 | 22 | 세 친구의 기억 봉인 → `L` 공명 → `J` 기억 탄환 12발. 체력에 따라 3단계 탄막으로 강화되는 수면 과학자 최종전 |

21스테이지에서 딸의 꿈 수호자를 멈추면 딸이 친구들의 꿈을 빼앗아 유지된 세계의 진실을 마주합니다. 그 직후 **PAGE 02**가 시작되고, 세계가 무너지는 것을 막으려 수면 과학자 자신이 거대한 보스로 등장합니다.

각 스테이지 사이에는 화자별 대화 장면이 재생됩니다. 하린·유나·하늘의 공포를 이해하는 장면, 딸이 진실을 받아들이는 장면, 그리고 PAGE 02 전환 장면까지 포함합니다. 장면별 일러스트 제작 가이드는 `STORYBOARD.md`에 정리되어 있습니다.
