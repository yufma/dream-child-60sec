## 공통 픽셀 아트 납품 규격

- 캐릭터 전신 원화: **64×96 픽셀 비율**, 투명 배경 PNG, 16~24색 중심 팔레트.
- 대화 초상 원화: **320×320 픽셀**, 픽셀 하나하나가 선명한 정사각형 격자, 확대 시에도 흐려지지 않게.
- 표현: 손으로 찍은 듯한 또렷한 1~2픽셀 외곽선, 제한된 색상, 작은 디더링, 셀 단위 하이라이트.
- 금지: 부드러운 페인팅, 벡터 느낌, 3D 렌더, 사진 질감, 블러, 자동 안티앨리어싱, 픽셀화 필터를 얹은 일반 일러스트.
- 모든 결과물은 특정 기존 게임/캐릭터를 복제하지 않는 오리지널 디자인이어야 한다. 텍스트·로고·워터마크는 넣지 않는다.
