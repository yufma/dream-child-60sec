# 하린 일러스트 프롬프트

투명 배경 PNG용 오리지널 **16비트 SF 꿈 판타지 픽셀 아트 캐릭터**. 64×96 픽셀 스프라이트 비율, 1~2픽셀 짙은 외곽선, 18~22색 제한 팔레트, 선명한 픽셀 계단선, 작은 디더링만 사용하고 부드러운 페인팅·3D·블러·안티앨리어싱은 사용하지 않는다. 11세 한국인 아이 하린, 달빛 유원지와 별 관찰을 좋아하는 밝은 성격. 짙은 남청색 단발, 하늘색 별 모양 헤어핀, 라벤더색 카디건, 별자리 자수가 있는 작은 크로스백, 편한 운동화. 손안에는 노란색으로 깜빡이는 작은 웃음 코어. 악몽에서 막 벗어나 조심스럽지만 다시 웃기 시작하는 표정. 회전목마 리본과 별가루를 3~5개의 단순 픽셀 효과로 표현. 달빛 파랑·라벤더·금빛 팔레트, 발끝까지 보이는 3/4 전신 구도. 기존 IP, 광대 분장, 로고, 글자, 워터마크, 공포/폭력 표현은 제외.

변형 요청: 기본은 회복 직후의 미소. 같은 외형으로 악몽 전의 불안한 표정과 엔딩의 활짝 웃는 표정을 각각 만든다.
